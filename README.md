## 一个 Windows 桌面工具，帮你自动录制抖音直播

有时候想保存一场抖音直播，但主播开播时间不固定，手动守着很麻烦。

抖音直播录制就是为这个场景准备的：把主播添加到软件里，设置好录制方式和保存目录，软件就可以帮你检测直播状态，并在需要时调用 `ffmpeg.exe` 录制直播内容。

简单来说，它是一款面向抖音直播的桌面录制工具，适合想要保存直播素材、回看直播内容、整理直播资料的用户。

## 它能做什么

- 自动检测抖音直播间状态
- 支持添加多个主播任务
- 支持监控录制和手动录制
- 支持原画、超清、高清、标清等画质选择
- 支持按时间或文件大小分段录制
- 支持调用本机浏览器登录抖音并保存 Cookie
- 使用外置 `ffmpeg.exe` 录制，方便后续替换和维护

最实用的地方是：添加主播后，不需要一直盯着直播间。开播后可以开始录制，下播后停止录制，适合长时间挂机使用。

## 使用方式：下载v1.0版程序

### 第 1 步：准备程序

1. 解压发布包。
2. 找到 `抖音直播录制_V1.0.exe`。
3. 将 `ffmpeg.exe` 放到同一个文件夹。

目录示例：

```text
抖音直播录制/
  抖音直播录制_V1.0.exe
  ffmpeg.exe
```

### 第 2 步：启动软件

双击运行：

```text
抖音直播录制_V1.0.exe
```

首次启动后，软件会创建本地配置目录，用来保存主播列表、录制设置和登录状态。

### 第 3 步：登录抖音

点击软件里的 **登录抖音**。

软件会打开本机浏览器完成登录。登录成功后，软件会自动读取并保存 Cookie，用于后续获取直播信息。

如果提示登录状态异常，可以重新点击登录刷新 Cookie。

### 第 4 步：添加主播

点击 **添加主播**，按提示输入抖音号或直播间信息。

添加成功后，主播会出现在任务列表中。软件会保存主播列表，下次启动时自动加载。

### 第 5 步：调整录制设置

可以在设置里调整：

- 保存目录
- 检测间隔
- 默认画质
- 默认添加模式
- 分段录制方式

画质可选：

```text
原画 / 超清 / 高清 / 标清
```

实际能录到的画质，以直播间返回的可用清晰度为准。

### 第 6 步：开始录制

软件支持两种模式：

**监控录制**  
适合挂机。主播开播后自动录制。

**手动录制**  
适合临时录制。选中主播后手动触发录制。

录制文件默认保存为 `.ts` 格式，适合直播场景。即使中途断网，已录制部分通常也更容易保留。

### 第 7 步：停止录制

可以在软件里停止录制或关闭程序。

程序会尽量正常结束 `ffmpeg.exe` 进程，避免录制文件损坏。

## 常见问题与解决方案

### Q1：为什么提示找不到 FFmpeg？

请确认 `ffmpeg.exe` 和主程序在同一个目录。

正确示例：

```text
抖音直播录制_V1.0.exe
ffmpeg.exe
```

### Q2：为什么获取直播失败？

常见原因：

1. 主播当前没有开播。
2. 登录 Cookie 过期。
3. 网络不稳定。
4. 请求过于频繁，被平台临时限制。

可以尝试重新登录抖音，或者等待一段时间后再试。

### Q3：录制的视频在哪里？

录制目录可以在软件设置里查看和修改。

如果没有修改，一般会保存到软件默认的下载目录。

### Q4：能不能同时录多个主播？

可以。软件支持添加多个主播任务，但实际录制效果会受电脑性能、网络带宽和磁盘速度影响。

## 一些实用技巧

### 1. 优先使用 `.ts` 录制

直播录制建议使用 `.ts` 文件。遇到断网、关机或异常中断时，已录部分通常更容易播放和修复。

### 2. 原画更清晰，但文件更大

如果磁盘空间有限，可以选择高清或标清。

### 3. 长时间录制建议开启分段

可以按时间或文件大小分段，方便后续整理，也能减少单个文件过大的风险。

### 4. 长期挂机前先测试一次

建议先添加一个主播，手动录制一小段，确认能正常生成文件后再长期挂机。
